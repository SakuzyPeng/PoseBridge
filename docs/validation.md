# 验证记录

日期：2026-09-19。环境：MacBook Pro M4 Pro、48 GB 内存、macOS 27.0、Rust 1.96.0。
此表区分软件契约、实物通信和尚未验证的定位 / 性能；不以单个平台通过代替其他平台。

## 软件检查

- Release 核心契约测试：8 项通过，覆盖数据解析、7 组姿态向量、安装转换、OSC 编码 / 限速、失联恢复、生命周期。
- Unix 伪串口测试：2 项通过，覆盖真实异步串口收发与 OSC、拆包、失联恢复、EOF，以及配置回读和不隐式保存。
- Release CLI → 本机 UDP：Euler 和四元数消息均由独立 Python 解码器验证通过。
- 真实 C 调用程序：动态库加载 / 链接、版本、结构大小、缓冲不足、无数据、重复轮询、停止和重启通过。
- 动态库迁移：使用 `@rpath/libposebridge.dylib`，复制到独立临时目录后编译和运行 C 调用程序通过，无本机编译目录依赖。
- macOS 动态库最初遇到 strip 后 Mach-O 字符串表对齐错误；关闭额外 strip 后 C 链接与运行通过。
- 格式与 Clippy：`cargo fmt --all --check` 与 Release 全目标 Clippy（`-D warnings`）通过。

## macOS 实物通信

传感器广播名称为 `WT901BLE68`，商品型号 BWT901BLECL5.0；固件版本尚未读取确认。
连接使用本机内置蓝牙，未购买专用适配器，也未调用系统常规配对流程。

| 路径 | 本次结果 | 限制 |
|---|---|---|
| BLE 扫描 | 成功发现设备并取得平台 UUID | UUID 属于本机身份，不写入通用配置 |
| BLE 角度通知 | 8 秒诊断窗口中连接后收到 57 份有效角度，主机观察约 9.88 Hz；无丢弃字节、无效姿态或重连 | 包含连接建立时间；保留默认设备回传率，没有执行配置写入 |
| BLE 四元数寄存器读取 | 8 秒诊断窗口中连接后收到 100 份四元数，约 16.17 Hz；无解析错误或重连 | 程序最高请求节奏 50 Hz，实际返回远低于 200 Hz；只发读取寄存器命令 |
| USB Rust 实机 | 115200、8N1；两次独立 4 秒运行的最后状态分别为 37／38 份角度，均约 9.93 Hz；无丢弃字节或无效姿态 | 已验证正常关闭后可再次打开；未执行物理拔插或回传率写入 |
| USB → 本机 OSC | 4 秒窗口收到 40 个四元数数据报，地址、类型及单位范数检查通过 | 使用显式安装基底验证数据流，不代表耳机安装方向或音频定位已验证 |

上述角度与四元数率是各自独立采集窗口的主机观察，不能相加，也不是传感器内部采样率。
BLE 原始角度在连接初期有变化，尚未完成稳定性、安装方向、漂移或磁场校准验收，不据此声称定位精度。
