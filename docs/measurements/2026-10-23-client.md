## 只读实机

设备为 WT901BLE68（BWT901BLECL5.0），测试安装映射为右 −Y、前 +X、上 +Z。
该映射用于验证数据流，不代表已经完成实际佩戴方向验收。

- macOS：首次 BLE 扫描在授权期间超时；授权后重新扫描、选择和连接成功，界面观察到约 99 Hz 设备采样。
  独立 UDP 接收器在 30.00 秒内接收 724 个有效姿态包和 41 个心跳，解码错误为 0，姿态约 24.10 Hz。
  这是当前 BLE 批量交付和合并后的发送率，不是传感器内部速率或时延测量。
- macOS：最小化窗口后继续观察 15 秒，各秒收到 23–26 个有效姿态包，没有空秒或解码错误。
- macOS：显式断开后打开只读磁场会话，约 4.9 Hz，磁传感器类型 6、CALSW 0，覆盖网格与读数更新正常；
  关闭后回到未连接状态，未自动恢复姿态或 OSC。
- Windows：BLE 扫描成功；显式运行客户端的两项实机用例，设备检查／姿态读取／停止和只读磁场会话／停止均通过。
  磁场约 4.72 Hz、类型 6、CALSW 0，设备检查确认没有配置写入。短姿态窗口不用于报告稳定采样率。

两台机器本轮均没有可用的 USB 串口设备。USB 实机读取／物理拔插、实际佩戴三轴运动、校准精度及掉电保存
仍待相应实机验收。真实设备测试没有启动校准、归零、修改融合／回传配置或保存 Flash。

## 构建与工作区

macOS 使用已有共享 target 和 Cargo registry；Windows 使用已有项目 target 和 registry。
Windows 原有未提交文件经逐项核对，对应本地已有的磁场功能提交；同步前已保留 Git stash，未覆盖丢弃。
本轮本地应用包由提交前的工作区构建，manifest 标记 source_dirty=true，并提供可执行文件 SHA-256。

应用包为本地开发产物：macOS 使用 ad-hoc 签名，未公证；Windows 未进行发布者签名。
CI 已增加双平台打包及产物上传步骤。上述验证结果来自两台原生主机，后续 CI 结果以对应提交的工作流记录为准。
