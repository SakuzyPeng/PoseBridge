# 0.6 磁场接口验证（2026-09-22）

实现独立磁场监测／校准会话，C ABI 400 布局与 OSC 3 不变；新增 C 导出和磁场 JSON schema 1。

## 自动验证

- macOS：格式检查、Clippy（所有 targets，warnings deny）、Release 构建及 workspace 测试通过。
- Windows x64：在已有 checkout／target 下完成同样的原生检查；新增跨平台磁场数据模型测试通过。
- 两平台真实 C11 调用通过 ABI 400 布局、JSON 缓冲区、无数据和游标合约检查；头文件内容一致。
- 两平台现有 C11 消费示例与 CLI→OSC 四种组合回归通过。
- macOS 12 项磁场专项测试覆盖单位、未知类型、类型读取失败降级、历史／年龄／窗口、控制写入、
  外部校准、取消、读超时、断线、开始核验失败及有界清理；无隐式 SAVE 或重发开始。
- macOS 通过假串口调用真实 C 动态库和 CLI，验证完整校准／显式保存流程、互斥 Busy、
  游标续读／重置、冻结统计、销毁清理、清理失败，以及带 `--save` 的 Ctrl-C 仍不保存。
  夹具只在测试子进程中为 PTY 模拟硬件波特率 ioctl；正式串口逻辑不改，Windows 不运行 PTY 测试。

## 实机读取

| 平台／链路 | 结果 |
|---|---|
| macOS USB，115200 | 30 秒收到 150 份样本，实际回包率 4.951 Hz；类型 6，比例 1/120 µT/count；开始／结束 CALSW 均为 0；无历史溢出，关闭后 fresh=false |
| macOS BLE | 本轮 3 秒及 8 秒扫描均无可发现设备，未执行读取验收 |
| Windows USB | 本轮枚举无可用 USB 传感器，未执行读取验收 |
| Windows BLE | 本轮 8 秒扫描无可发现设备，未执行读取验收 |

[原始统计报告](2026-09-22-magnetic-usb.json)仅保留汇总信息，不包含本机端口／设备身份。
实机仅运行 `magnetic monitor`，没有开始校准、结束校准或保存写入。
