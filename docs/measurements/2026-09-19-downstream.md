# PoseBridge 0.3 下游与设备控制验证

日期：2026-09-19。当前协议 3、PoseBridge ABI 300、Render 头追 ABI 1.42。
维护者确认没有实际旧消费者，本次统一移除旧草案兼容；音频 ABI 保留。

## 软件

- macOS Release：28 项 Rust 核心／契约／时间戳／控制测试通过，包含 Unicode 来源名、原子快照、独立元数据心跳、只读检查、六轴前置条件、控制保存边界、取消与参考失效。
- 格式、全目标 Clippy、真实 C 调用和迁移加载通过；当前 PbPose/PbStatus 为 184/136 字节。
- 独立 Python 解码四组 CLI 输出（Euler/四元数 × 缺失/合成时间）通过；元数据不计作姿态，旧 --osc-version 被拒绝。
- Render Debug：头追契约、纯 C 头文件与既有音频 C ABI 三个目标通过。接收来源、实例和乱序检查，500 ms 姿态／3 秒心跳独立超时，JSON 所有权与完整快照均覆盖。
- Release 真动态库与实际 CLI 联调通过，四个源实例共接收 515 份姿态、22 份元数据；忽略另一个逻辑来源 135 个数据报，无拒绝包或 tx 缺口。
- 校准、角度参考、航向归零和恢复默认只用伪设备检验命令流程／报告语义，未对实物执行这些动作；不能据此声称校准精度或掉电持久化通过。

## macOS 实物

WT901BLE68，设备回读版本 13115。以下为 Release 原生采集与 Render C ABI 联调；初始/最终配置均为 10 Hz、motion、nine_axis。

| 路径 | 窗口 | 姿态 OSC 包 | 与源快照匹配核验 | 结果 |
|---|---:|---:|---:|---|
| USB | 首帧后约 4 秒 | 398 | 398 | 只读 inspect、显式可恢复配置、快照/OSC/Render 一致性、停止失活通过 |
| BLE | 首帧后约 4 秒 | 100 | 96 | 同上；被动采集期间没有后台配置寄存器轮询 |

临时配置为 100 Hz、timestamp_gyro_quaternion；显式测试 six_axis/nine_axis 回读后恢复原模式。
测试结束均重新 inspect 确认原回传率、输出与算法值。未 SAVE、校准、归零或恢复默认。
原始结果保留在本机 target/benchmarks/downstream，避免把机器标识和完整设备记录放入仓库。

## Windows 与最终检查

- Windows x64／Rust 1.98 MSVC：20 项跨平台 Rust 测试、fmt、Clippy、Release 构建、生成头文件一致性、真实 C ABI 迁移调用、独立 CLI 解码均通过。8 项伪串口测试仅在 macOS 运行。
- MSVC 14.51：原生接收器、协议和完整 adm_c_api.cpp 翻译单元编译通过，C 头文件布局程序运行通过，C 接入示例编译通过。
- 原生 C++ 接收器分别接收 125 份四元数和 125 份 Euler，携带独立状态／来源信息；过滤、协议版本、元数据关联、合成时间精度、停止失活和端口释放通过。
- Windows BLE：只读检查、六／九轴显式切换及恢复、100 Hz / timestamp_gyro_quaternion 临时配置通过；约 4 秒收到 101 个姿态包，100 个与轮询源快照匹配。结束再次检查确认 10 Hz、motion、nine_axis。
- macOS 真实 C 下游示例运行通过，收到 129 份姿态，完成来源过滤、参考变化回调、失联冻结和 JSON 释放。
- 最终改动范围 clang-format、clang-tidy、cppcheck 通过；文档相对链接通过。GUI 没有修改。
